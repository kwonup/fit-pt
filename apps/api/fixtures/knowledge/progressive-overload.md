# 점진적 과부하 학습용 메모

> 이 문서는 ingestion 파이프라인을 검증하기 위한 프로젝트 자체 작성 fixture입니다. 의학적 조언이나 실제 논문의 대체 자료가 아닙니다.

점진적 과부하는 같은 운동을 반복하면서 중량, 반복 횟수, 세트 수, 동작 품질 가운데 하나 이상을 점진적으로 개선하는 접근이다. 매번 모든 지표를 올릴 필요는 없으며, 기록이 안정적으로 수행될 때 작은 폭으로 조절한다.

운동 성과는 자극뿐 아니라 회복과 함께 해석해야 한다. 수면 부족, 통증, 비정상적인 피로가 있다면 이전 기록보다 낮은 강도를 선택할 수 있다. 날카로운 통증이나 지속되는 증상이 있으면 운동을 중단하고 자격을 갖춘 전문가의 평가를 우선한다.
